농산물 도매가격을 예측하는 머신러닝 모델입니다. 공공 API 5개를 매일 자동 수집해 BigQuery 에 쌓고, 그 데이터로 7거래일 뒤 가격이 오를지 내릴지를 예측합니다. 예측은 매일 기록되고 열흘 뒤 실제 가격으로 채점됩니다.

여기 나오는 숫자는 전부 모델의 예측입니다. 사실이 아니고, 맞을 때도 틀릴 때도 있습니다. 위 성적은 과거 데이터로 잰 값이며 실전 검증은 아직 진행 중입니다.

출하할 물건을 오늘 낼지, 열흘쯤 두었다 낼지만 봅니다.

읽는 법

  1. 모델은 7거래일 뒤(약 열흘) 도매가가 오늘보다 오를지 내릴지만 맞힙니다. 얼마나 오를지는 못 맞힙니다.
  2. 확률이 한쪽으로 충분히 기운 날만 말합니다. 애매한 날은 아무 말도 하지 않습니다.
  3. 열흘을 못 버티는 품목은 미룰 수가 없어 대상에서 뺍니다 (시금치·미나리처럼 저장 7일짜리).

오늘 행동할 것

모델이 애매하다고 한 품목

확률이 반반에 가까워 신호를 내지 않습니다. 평소대로 하면 됩니다.

미룰 수 없어 뺀 품목

저장 가능 일수가 열흘 미만이라, 오를 것 같아도 창고에 둘 수 없습니다. 확률이 높아도 여기 있으면 오늘 내보내는 게 맞습니다.

달마다 하는 말이 다릅니다

막대는 그 달에 모델이 확신한 날이 몇 번이었는지, 선은 그중 "미루라"고 한 비율입니다. 여름(6~7월)엔 확신하는 날이 많고 거의 다 미루라고 하며, 가을(9~11월)엔 반대로 오늘 팔라고 합니다. 오늘 신호가 전부 "미룸"인 것도 8월이라서입니다.

참고용입니다. 이 신호는 확률이지 확정이 아니며, 실전 검증은 아직 진행 중입니다. 출하 결정의 책임은 이 사이트에 없습니다.

무엇으로 예측하나

5개 공공 API 를 모아 날짜 × 품목 한 줄로 접습니다. 가격·달력만 쓰고, 출하량·기상은 값을 하지 않아 뺐습니다.

적게 고를수록 잘 맞히지만 행동할 날이 줄어듭니다. 운영 지점은 확신도 0.20 입니다.

확신도는 이렇게 퍼져 있습니다

대부분의 날은 애매합니다. 오른쪽 꼬리만 골라 행동합니다.

확률이 정직한가

"70% 오른다"고 한 날이 실제로 70% 올랐는지 봅니다. 대각선에 붙을수록 믿을 만합니다.

무엇을 못하는가

이 프로젝트에서 가장 많은 시간을 쓴 건 안 되는 것을 확인하는 일 이었습니다.

값은 못 맞힙니다

몇 % 오를지는 예측하지 못합니다. 맞히는 것은 방향뿐입니다. 변화율 예측은 naive("안 변한다") 대비 개선이 미미했습니다.

시기를 많이 탑니다

반년 단위로 갈라 재면 적중률이 11%p 벌어집니다. 모델을 바꾸는 것보다 시기가 훨씬 큽니다. 한 달 성적으로는 판단이 서지 않습니다.

피처를 더 넣어도 안 늘었습니다

출하량·기상을 붙였다 뗐고, 앙상블·확률 보정·다른 모델 계열도 전부 노이즈 범위였습니다. 지금 피처로는 여기가 한계입니다.

작은 차이는 발견이 아닙니다

무의미한 피처를 넣고 값을 흔들어 잡음의 폭을 먼저 쟀습니다. 그보다 작은 개선은 채택하지 않았습니다.
